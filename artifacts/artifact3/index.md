# Artifact 3: Understanding Machine Learning Training Methods

## Overview

This artifact is based on my coursework activity, "Questions about
Training Methods." The activity helped me develop a better understanding
of how different machine learning approaches are trained and when each
approach can be applied to real-world problems.

## Learning Objective

The purpose of this activity was to understand different machine
learning training methods and how they can be selected based on the
type of data and problem being addressed.

## What I Learned

Through this activity, I explored three important approaches to
machine learning:

- **Supervised Learning** – learning from labeled training data to
  make predictions or classifications.
- **Unsupervised Learning** – identifying patterns or structures in
  data without predefined labels.
- **Reinforcement Learning** – learning through interactions with an
  environment using rewards and penalties.

Understanding these differences helped me recognize that the choice
of training method depends on the problem, available data, and desired
outcome.

## AI/ML Skills Demonstrated

This artifact demonstrates my ability to:

- Identify different machine learning training approaches.
- Distinguish between supervised, unsupervised, and reinforcement learning.
- Connect machine learning methods to real-world applications.
- Evaluate which learning approach may be appropriate for a given problem.
- Explain technical AI/ML concepts in a clear and understandable way.

## Real-World Applications

| Training Method | Example Application |
|---|---|
| Supervised Learning | Email spam classification |
| Unsupervised Learning | Customer segmentation |
| Reinforcement Learning | Robotics and game-playing systems |

## Reflection

This activity helped me understand that machine learning is not based
on one universal training approach. Different problems require different
learning strategies depending on the type of data available and the
goal of the model.

One of my main takeaways was that understanding the characteristics
of a problem is an important step before selecting a machine learning
method. This knowledge will help me make better decisions when working
with AI and ML applications.

Rather than focusing only on comparing technologies, this activity
shows my understanding of how machine learning models can learn from
different types of data and how training approaches can be applied
